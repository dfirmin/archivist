## Defects found and fixed

1. **Fabricated timestamps** (`T00:00:00Z`) on `generated` and `verified` → author and verifier
   take `<now>` from `date -u +%Y-%m-%dT%H:%M:%SZ`.
2. **Empty enricher headings** when enrichment found nothing → the author never writes enricher
   sections; the enricher adds them (and parents) only with content.
3. **Reference wording leaked into the body** ("authoritative source", "loaded into the
   warehouse") → author step 5/6 rules; the example structure no longer tells the author to name
   registered systems (the gap-kind checks that).
4. **`undefined_acronym` flagged ordinary words** (`CASE`) → example contract detection refined;
   `SV`, `CD` added to the example naming standards. A contract fix, not an engine change.
5. **Optional sections stubbed** (`### Implementation Logic`) → `required: false` author sections
   are written only when a source supports them.
6. **Log date in local time** vs UTC stamps → catalog uses `date -u`.
