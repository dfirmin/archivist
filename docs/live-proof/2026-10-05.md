## Defects found and fixed

1. **`--concept all` selected companion stubs.** The first wh selection included the two
   `View` companions, which a full run never judges or scores; rescoring them would have
   stamped `okfx_confidence: 1.0` on stubs. `all` now means `authored: true` concept types.
2. **The conductor skipped the prune on one concept of three (H2).** No harm in that run (the
   concept held no removed kind), but the rule is the only thing that removes stale kinds.
   Python now prunes every selected concept before each session (H2b proves it); the `before`
   rule stays, worded for every concept, for authoring runs.

## Not proven here

- Publishing: the workspace's GitHub token was invalid, so `file-gap-issues` closing an issue

  live.
- A fence failure live (covered offline: body, other field, out-of-scope and new-file cases).
- `anthropic-api` and `gateway-key` modes (the runner and auth are unchanged).

1. **A waiting group ended the scan.** Runner: hold a planned first group that took no
   documents and plan on without it; kickoff lists held documents; planner leaves them out.

   Planner: an extract joins the group of the documents about the same concept, after them.
   Handbook contract: runbook identity matches the same incident whatever the wording.
3. **Written notes classified as a transcript.** Example contracts describe a transcript's
   shape (timestamped speaker lines) and say notes are not transcripts.
4. **An amendment that restates its rule was classified as a policy.** Handbook contract:
   class descriptions say an amendment states what changed even when it restates the rule.

Also written down: a concept a group creates keeps `okfx_placement: new` through that group (W2
showed it; the rule now says so).
